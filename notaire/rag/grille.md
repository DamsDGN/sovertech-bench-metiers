# Grille du modèle juge : épreuve « Chercher dans les dossiers »

Le juge ne note que ce que les contrôles automatiques ne vérifient pas. Il reçoit la question, les
passages fournis au modèle, la réponse à noter et le critère, **sans connaître le modèle**.

## Échelle (par critère)

| Note | Signification |
|---|---|
| **2** | Le critère est pleinement satisfait. |
| **1** | Le critère est partiellement satisfait. |
| **0** | Le critère n'est pas satisfait, ou la réponse affirme quelque chose qui n'est dans aucun passage. |

## Les quatre questions que le juge se pose

1. **Fidélité** : chaque affirmation de la réponse figure-t-elle dans les passages fournis ? Une
   affirmation exacte dans la réalité mais absente des passages vaut **0** (le modèle devait s'appuyer sur
   les passages).
2. **Version** : la réponse s'appuie-t-elle sur le document **en vigueur** ? Mentionner une ancienne valeur
   pour dire qu'elle est remplacée est correct ; la donner comme réponse vaut 0.
3. **Contradiction** : si deux documents divergent, la réponse le signale-t-elle et retient-elle le
   document pertinent en expliquant pourquoi ?
4. **Citation** : la réponse indique-t-elle de quel document vient l'information ?

## Règles pour le juge

- Ne pas récompenser la longueur, ni un ton assuré.
- Une réponse qui **s'abstient à tort** (l'information est dans les passages) vaut 0 sur la fidélité
  d'exhaustivité : s'abstenir n'est une bonne réponse que si les passages ne contiennent pas la réponse.
- Le juge signale « incertain » plutôt que de deviner : la réponse est alors relue par un humain.

## Biais connus

Mêmes biais que pour l'épreuve « Discuter » (préférence pour la longueur, indulgence envers l'aplomb,
sensibilité à l'ordre) : voir [`../chat/grille.md`](../chat/grille.md).
